# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions, bug reports,
bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

### Reporting Bugs

- Open an issue on GitHub describing the problem.
- Include the steps to reproduce it, the expected result, and the actual result.
- Mention your Python version and operating system.

### Suggesting Enhancements and Ideas

- Open an issue describing your idea and why it would be useful.
- Discuss the idea with the maintainers before starting large changes.

### Fixing Bugs and Improving Documentation

1. Fork the repository.
2. Create a new branch: `git checkout -b my-feature-branch`
3. Make your changes and test them by running `python simple_interest.py`.
4. Commit with a clear message: `git commit -m "Describe your change"`
5. Push your branch: `git push origin my-feature-branch`
6. Open a Pull Request describing what you changed and why.

## Guidelines

- Keep code simple, readable, and documented.
- Follow the existing code style (PEP 8 for Python).
- Be respectful and follow the project's Code of Conduct.
